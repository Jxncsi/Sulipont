# 8. Agilis retrospektív és jövőkép

|---|---|---|
| | | |
| | | |
| | | |

Segédkérdések:

- Tartottuk a határidőket? Hol csúsztunk, és miért?
- Mindenki a saját szerepében dolgozott? Hol volt átfedés vagy hiány?
- Hasznos volt a Trello tábla, vagy csak utólag vezettük?
- Beszédesek voltak a commit üzenetek? Használtuk a megbeszélt ágstratégiát?
- A három modul közül melyik volt a legnehezebb, és miért?
- Mit tennénk másképp, ha újra kezdenénk?

## Önértékelés

Csapattagonként néhány mondat: mit tanultam, miben fejlődtem, miben kértem segítséget.

## Továbbfejlesztési lehetőségek

1. **Bejelentkezés és jogosultságok:** diák, tanár, portás; csak a saját hirdetés vagy tárgy törölhető, a dolgozatot csak tanár vehet fel.
2. **Szerveroldali adatbázis:** több gépen közös adatok (pl. egy kis REST API).
3. **Értesítések:** e-mail vagy push, ha a tárgyadat igényelték, vagy ha torlódás keletkezett.
4. **Üzenetküldés** a hirdető és az érdeklődő között a börzén.
5. **Ünnepnapok, szünetek** kezelése a dolgozatnaptárban, és az órarendből betöltött adatok.
6. **Talált tárgyak:** QR-kód a portán, kamerás feltöltés közvetlenül a telefonról.
